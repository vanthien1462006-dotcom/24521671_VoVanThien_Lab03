  ## Part 6. Homework 2: Polyphonic 88-Key Piano & FIFO Sequencer

  ### 6.1 Overview
  `GrandPiano88` (src/homeworks/GrandPiano88/) generates an 88-key piano (A0,
  midi 21, to C8, midi 108) from the formula f = 440 × 2^((midi − 69) / 12). A
  Web Audio synth plays up to 8 voices and steals the oldest voice first (FIFO,
  ES6 Map). Each key is a `React.memo` component, so pressing one key
  re-renders only that key. A recorder stores `{ midi, freqHz, durationMs,
  deltaMs }` events and replays them at 0.5x, 1x or 2x; Stop Sequence and
  unmount cancel the replay with an AbortController. Source: slides 27 and 28.

  ### 6.2 Contract
  ```js

   * @typedef {Object} PianoKeyData
   * @property {number} midi       21 to 108.
   * @property {string} noteName   Sharp names, for example 'A0', 'C#4'.
   * @property {boolean} isBlack
   * @property {number} freqHz     440 × 2^((midi − 69) / 12).
   */

  /**
   * @typedef {Object} KeySlot
   * @property {PianoKeyData} white
   * @property {PianoKeyData | null} black   The black key that follows the
  white key, if any.

   * @property {number} midi
   * @property {number} freqHz
   * @property {number} durationMs  Time the note was held.
   * @property {number} deltaMs     Time since the previous note started (0 for
  the first).
   */

  /**
   * @typedef {Object} ScheduledNote
   * @property {number} midi
   * @property {number} freqHz
   * @property {number} startMs     From the start of the replay, already
  divided by the speed.
  ```

  Thêm vào CUỐI "## 18. Homework 2 rules: polyphony, memo and sequencer" với
  các ### và gạch đầu dòng sau (giữ nguyên chữ):

  Generated keys

  - Piano keys are generated from midi numbers with f = 440 × 2^((midi − 69)
  / 12). Never hard-code key lists, note names or frequencies outside tests.

  Voices

  - Active voices live in a Map in insertion order. At the voice limit, release
  voices.keys().next().value first (FIFO stealing).
  - Every voice ramps its gain with exponentialRampToValueAtTime to 0.0001
  before oscillator.stop. Never stop a voice at full gain.

  Memo

  - Each piano key is a React.memo component. Callbacks passed to it are stable
  (useCallback) and its pressed prop is a boolean, so one press re-renders one
  key. Verify with the React DevTools Profiler.

  Sequencer

  - The UI mode is one state value: 'idle' | 'recording' | 'playing'.
  - Recording stores { midi, freqHz, durationMs, deltaMs } in order. Replay is
  computed by a pure schedule function and awaited with an abortable delay.
  - Stop and unmount abort the replay's AbortController, stop all voices and
  release every pressed key. AbortError is a normal outcome.
