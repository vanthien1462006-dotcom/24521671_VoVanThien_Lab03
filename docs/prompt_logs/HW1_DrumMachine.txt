  App shell

  - One view is shown at a time, chosen from the URL hash by
  src/shell/resolveView.js; an unknown hash shows the exercises. The hash is
  read with useSyncExternalStore subscribed to hashchange. No router package.
  - Shell code lives in src/shell/. Each homework adds its view id, its nav
  link and its view branch in its own commits.

  Keyboard

  - Global shortcuts listen on window with e.code. Never keyCode, which or
  charCode, and never read physical letters from e.key.
  - Ignore e.repeat, Ctrl, Alt and Meta combinations, and events whose target
  is an input, textarea, select or contenteditable element.
  - Shortcuts can be turned off by the user (WCAG 2.2 SC 2.1.4). Listeners are
  removed in the effect cleanup and are not added while shortcuts are off.
  - Held pads are released on keyup and on window blur.

  Web Audio

  - Create the AudioContext lazily inside a user gesture, never at module load
  or during render. Close it when the homework unmounts.
  - Every source is started and stopped with explicit times. Gain ramps to
  0.0001 with exponentialRampToValueAtTime before the stop, so there is no
  click.
  - Audio code takes an injectable context factory so unit tests run with a
  fake context.

  Live feedback

  - Hits are announced in one output with aria-live='polite'. Lists are capped
  and keyed by stable ids.
  - Animation-frame loops live in the smallest component that needs them and
  are cancelled in the effect cleanup.

  behind H1-T08: e.code is safe with UniKey for every pad key.

  assumption that e.code is always filled.

  Bug: With UniKey in Vietnamese Telex mode, the W key reaches the page as an
  event with an empty code and key "ư". padMap.get('') finds nothing, so the
  Kick pad does not play. A and D arrive as KeyA and KeyD and play normally
  (Total hits 2).

  DevTools Proof: Console screenshot
  docs/evidence/HW1_DrumMachine/hw1-07-unikey-ecode.png (added in H1-T22):
  code:  | key: ư, code: KeyA | key: a, code: KeyD | key: d. Detected by
  running a keydown listener in the Console with UniKey Telex on and pressing
  W, A, D.

  Engineering Fix (Commit ea60b22): e.code is kept, because the task requires
  it and project-rules section 17 forbids reading letters from e.key. The limit
  and the workaround (switch UniKey to English mode, or use the pointer) are
  documented under Known limits in the README.
