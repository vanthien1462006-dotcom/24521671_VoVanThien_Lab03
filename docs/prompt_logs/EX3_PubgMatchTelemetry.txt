  ## Part 4. Exercise 3: KRAFTON PUBG VN Live Match Telemetry

  ### 4.1 Overview
  `PubgMatchTelemetry` (src/components/PubgMatchTelemetry.jsx) shows live PVS
  telemetry for three Vietnamese squads (CES, TE, GE). A selector inside the
  component switches squads. A four-state machine (IDLE, LOADING, SUCCESS,
  ERROR) drives the view. Each squad switch or retry starts a real fetch of a
  local JSON file with an AbortController; the previous request is aborted in
  the effect cleanup. 35% simulated packet loss leads to an accessible error
  alert with a Reconnect Satellite button. Source: slides 20 to 23.

  ### 4.2 Contract
